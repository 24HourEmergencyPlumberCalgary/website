3. Core Web Vitals & Speed Optimization (P0 Priority)
Google’s Core Web Vitals are confirmed ranking factors. Failure to meet these thresholds will result in ranking loss.
•	Largest Contentful Paint (LCP): Must be ≤ 2.5 seconds.
o	Implementation: Inline critical CSS for above-the-fold content. Defer non-critical JS.
•	Interaction to Next Paint (INP): Must be ≤ 200 milliseconds.
o	Implementation: Minimize JavaScript execution time. Avoid heavy third-party scripts (chatbots, trackers) on critical pages unless absolutely necessary.
•	Cumulative Layout Shift (CLS): Must be ≤ 0.1.
o	Implementation: Set explicit width and height attributes for all images and videos. Do not inject UI elements dynamically.
